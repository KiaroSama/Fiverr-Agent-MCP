# Contributing

Read the shared glossary CONTEXT.md, docs/architecture.md and capability dispositions before changes. Keep Rust application logic independent of transport/browser/filesystem adapters; do not introduce a development-runtime wrapper or unsupported platform endpoint.

Use locked Rust1.99 and the configured native CI. Keep files below800lines, source UTF-8, tests bounded/meaningful and private files out of source/artifacts. Preserve exact integer money, account scope, input/file validation, manual consent, fail-closed route policy and upstream licenses. A fixture cannot stand in for current platform permission/live behavior.

Explain the actual requested behavior, affected seam, evidence and remaining limitations. Never weaken tests, silently change account/route or add account mutation without the shared approval/journal contract. Build/release scripts and exact corresponding source are part of the deliverable. Do not submit private content or secrets in a commit, pull request or issue.
