# Domain Docs

Read root `CONTEXT.md` for the single Fiverr operations glossary, and relevant `docs/adr/` decisions when present. Use canonical terms: a local Draft is not a sent message; a Manual handoff is not a platform success; an Observation is not verified-current account state. Challenge contradictions before implementation.

Spec Kit owns requirements/design/tasks; this file is vocabulary routing only. No second spec is created by a skill. Missing ADRs need no placeholder. Hard-to-reverse decisions get an ADR only when a real trade-off justifies it.
