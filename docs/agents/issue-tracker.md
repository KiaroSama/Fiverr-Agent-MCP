# Issue tracker: Local Markdown

The owner chose local Markdown task tracking. Spec Kit owns the single feature specification and dependency-ordered tasks under the active feature directory. Do not duplicate its spec/tasks in another tracker or publish private planning material as GitHub Issues.

Read `.specify/feature.json` to select the feature, then its `tasks.md`. Preserve completed task IDs and append request deltas. Local supplementary tickets may use `.scratch/<feature>/issues/NN-slug.md`; source publication does not switch the chosen tracker. GitHub is distribution, not authorization to publish tasks.
