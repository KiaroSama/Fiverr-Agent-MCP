# Security and responsible use

This unofficial experimental workspace is not a verified full Fiverr account automation service. Use only authorized account/data workflows and comply with platform terms. Manual credentials/challenges remain with the human; no CAPTCHA bypass, anti-detection, mass targeting or arbitrary execution.

Report suspected defects privately through GitHub's private vulnerability reporting if enabled; otherwise contact the repository owner to establish a private channel before sharing sensitive evidence. Do not attach tokens, cookies, private messages, customer files, browser profiles, authorization exports or raw database backups to public issues. Provide sanitized version/OS/operation/error/reproduction evidence.

No security certification, full audit or universal DNS/privacy guarantee is claimed. See docs/testing.md and docs/verification-report.md for coverage limits. Tokens protect the local HTTP endpoint by default; explicit trusted mode permits other local processes. Stop account automation when routing, permission, identity or upstream state is uncertain. Unknown outcomes must never be blindly retried.
